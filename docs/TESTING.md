## 外部参照

Python3.12.14、NumPy2.5.3、segyio1.9.14，固定随机种子20260922。332场景、1171项通过；版本、计数、源码SHA-256及测量在 evidence/reference.json。

1. segyio 实际生成和读取大小端、样本码1/2/3/5/6/8/9；检查样本、缩放坐标、分组、统计、选择、窗口及新建/格式转换回读。
2. 独立 Python struct 覆盖 rev0/1/2、大小端、ASCII/CP037、定长/变长、IEEE64精度和int64极值。24位码7由独立三字节整数参考验证；未列为 segyio 通过，因为该版本会错误回退为IBM解释。
3. 3200字节完整CP037组合与Python codec互核，包含全部256字节；新建也核对原始编码。rev2独立版本字节、小于1微秒间隔、扩展字段和未知头拒绝。
4. 已知IBM字节与400个随机指数/尾数；200个非法样本码变体、截断、异常扩展/尾部/偏移/声明计数。变体不是独立实测地震记录。
5. SVG由独立XML解析器读取，并核对单点标记、正负位置、样本数、有限坐标和不伪造时间跨度。六类CLI生成样本另外在本机Chromium浏览器实际查看，详见[图形输出核查](SVG-REVIEW.md)；不是跨浏览器或全数据集认证。CSV保留int64十进制值，非有限数据不会伪装有效数值。

常规浮点比较相对容差2e-6/绝对1e-7，IEEE64 struct对照绝对1e-14，int64为整数精确比较。数学测试包含已知RMS/总体差、1e300幅度平方溢出反例及不能准确表示的时间窗。独立参考不会取代格式规范，也不承诺所有仪器专用变体。
