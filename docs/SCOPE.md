# 固定范围与检查点

遵循五项目 BENCHMARK-STANDARD.md；不是只读头演示。

A/B：有界字节、大小端、ASCII/EBCDIC 文本、二进制头及 IBM32/IEEE32/IEEE64/有符号 8/16/24/32/64 位样本；64 位整数保存不经 Double。

C/D：rev0/1/2.0 的常用固定240字节道头，扩展文本头，定长/变长道扫描和索引，原始字节复制与正确改写。不支持的额外道头、布局重映射、pair-swapped、tape label/data trailer 明确拒绝，不假装覆盖 rev2.1 专有扩展。

E–H：坐标标量、按道/指定头字段筛选、道集分组、样本窗口、统计/RMS/死道/裁剪诊断、CSV/SVG。

I/J：实际文件 CLI、示例、拒绝覆盖、中文说明、公共 API、CI 配置；segyio/独立 struct 对照、适当规模测量、源码绑定记录。

库数据限额：文件256 MiB、1000000道、单道1000000样本、累计16000000样本、最多1024扩展文本块。不是恒定内存或地球物理反演器，不猜未知CRS，不把原始振幅冒充标定物理值。
